# Cycle 271 — reviewed subtitled batch MP4 export

## Scope
Offline recordings only, following `docs/VIDEO_ANALYZER_SCOPE.md`. Adds `offline_reviewed_subtitled_batch_export.py` alongside the existing single-clip exporter. This new module exports up to 12 reviewer-selected clips from up to four table IDs. It burns explanatory subtitles into the MP4 using FFmpeg/libass and also writes SRT files and a JSON manifest with SHA-256 hashes.

Input JSON: `{"schema_version":1,"time_basis":"playback_seconds","recording_sha256":"<64 hex>","clips":[{"review_id":"r1","table_id":1,"start_seconds":0.4,"end_seconds":1.4,"explanation":"Reviewed decision","human_reviewed":true}]}`. Timestamps are relative to playback start, NOT absolute source PTS. Review flags and text are self-attested, not authenticated or generated by poker analysis.

The exporter validates source bytes, source duration, intervals, table IDs, duplicate review IDs, subtitle text, input immutability, and new output paths. It stages results and only publishes after all clips finish. It never infers cards/actions, evaluates equity/EV, or selects clips automatically.

## Limitations and next steps
- Not integrated with automatic hand recognition, reviewed hand boundaries, equity/EV, or the upload UI.
- No 40–60-minute, 4K, Windows, nonzero-origin PTS or large-batch performance validation. Full upstream sampler/Tesseract orchestration without test doubles remains pending.
- The user-supplied `human_reviewed` field is not authenticated. The subtitles are supplied explanations, not independently validated poker conclusions.
- Output-directory create-only semantics rely on a new-path check followed by rename in a trusted workspace; cross-process races are not fully eliminated.
- Need an authorized annotated 3–5-minute PLO5/PLO6 video to measure real visual recognition accuracy.

# Cycle 254 — timestamp-scoped math inputs and conditional call EV

Scope: **offline review of recorded PLO5/PLO6 hands only**. No live poker, simulated playable tables, automated betting, credentials, production changes, or GitHub Actions.

## New modules

- `offline_math_decision_snapshot.py` accepts the existing manually reviewed street ledger and the existing math-gate assumptions **plus** `decision_timestamp_seconds` and `decision_street`. It validates chronological evidence, selects only hero/board cards confirmed by the decision timestamp, normalizes card suit case, and calls the existing `offline_math_input_gate.build`. It rejects incomplete boards, unresolved or rejected visible cards, overlaps, duplicate combos, and mismatched source hashes. The older whole-hand gate remains unchanged for compatibility.
- `offline_call_ev_from_counts.py` accepts a timestamp-scoped candidate and **externally supplied, unverified** Monte Carlo win/tie/loss counts. It checks hashes, seed, trial count, variant, heads-up Omaha rule declaration, and uniform opponent range weights. It computes `equity=(wins+ties/2)/trials`, `EV(call)=equity*(pot_before_call+to_call)-to_call`, `EV(fold)=0`, break-even equity, and a conservative two-sided 95% Hoeffding interval for independent samples in [0,1]. It does **not** run or verify a poker engine or issue a strategy verdict.

## Local verification

```sh
cd video_analyzer
python -m unittest -v test_offline_math_decision_snapshot test_offline_call_ev_from_counts test_offline_math_input_gate
```

Local replay on 2026-11-01: **63 selected tests passed** (28 snapshot, 18 conditional EV, 17 regression). Synthetic file roundtrips were executed for PLO5 and PLO6, each with a flop decision before turn/river. Synthetic outcomes of 200 wins, 100 ties, 200 losses yielded 50% equity and conditional EV(call) of 40 units for pot=100 and call=20. These counts are invented for arithmetic verification, **not** generated by Monte Carlo. The entire repository suite and Windows were not tested.

## Remaining blockers

- Need authorized, annotated 3–5-minute real session video to measure OCR/hand reconstruction accuracy.
- The existing Omaha Monte Carlo engine has not yet been connected to these modules or independently verified for uniform legal runouts and exactly two private plus three board cards.
- Weighted ranges, multiway pots, raise EV, future betting, rake, and real 40–60-minute processing remain unsupported/unverified.
- A Hoeffding confidence bound is valid only when the supplied outcomes are iid samples from the stated model; the module cannot establish this from a self-declared summary.

## Safety

No OCR observation is automatically treated as true. No future board card may enter an earlier decision. Inputs and outputs are SHA-256-linked, output files cannot overwrite existing files, and every report is marked conditional/unverified.

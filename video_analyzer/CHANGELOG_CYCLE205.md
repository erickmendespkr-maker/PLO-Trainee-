# Cycle 205 — offline visual review UI and human-explained MP4 bridge

Scope: `docs/VIDEO_ANALYZER_SCOPE.md`. Recorded PLO5/PLO6 only, up to four user-selected table regions. No live poker integration, playable tables, opponent AI, network calls, credentials, production changes or paid services.

## Published on `feature/plo5-plo6-training`

- `video_analyzer/offline_visual_review_ui.html`: publish the readable standalone UI, previously available only in the local Cycle 204 package. Users select ROIs with the pointer, import the FFmpeg timeline, seek candidate intervals and explicitly review them.
- Add a human explanation text area for each confirmed hand and export `plo_explanations.json` alongside `plo_decisions.json`. The existing `offline_review_plan_clip_bridge.py` consumes the explanations; they are not generated by AI or OCR.
- Align the UI's maximum hand interval with the existing MP4 exporter: 180 seconds, not 300. Validate nonempty human explanations (up to 1000 characters) and unique hand IDs before exporting.
- `video_analyzer/test_offline_visual_review_ui_smoke.py`: portable synthetic Chromium + FFmpeg smoke tests for the complete browser review → Python SHA-256 contract → reviewed clip plan → MP4/sidecar/manifest flow.

## Local verification

- 104 selected unittest executions passed in 26.190 seconds, including the browser tests, contract tests, timeline tests, ROI review and MP4 bridge. Logs: `final_tests.log` in the Cycle 205 artifact.
- Browser test generates a synthetic 320×192 H.264 recording with four independent quadrant changes; one manually confirmed interval yields an MP4 with a verified SHA-256. This does not validate poker-hand recognition.
- Browser tests use Playwright `page.set_content`; direct `file://` navigation returned `ERR_BLOCKED_BY_ADMINISTRATOR` in the sandbox. Opening the HTML directly on Windows is not verified.
- GitHub publication uses the exact files from the local tested source (verified by Git blob SHA-1). No GitHub Actions run.

## Reproduce locally

Requires Python, FFmpeg/FFprobe, Chromium and Playwright for browser tests:

```bash
cd video_analyzer
python -m unittest -v test_offline_visual_review_ui_smoke
```

Workflow: open `offline_visual_review_ui.html` locally, load an authorized recording, draw ROIs and export `rois.json`; run `python offline_manual_roi_review.py analyze VIDEO rois.json timeline.json`; import the timeline, review candidates and export `decisions.json` plus `explanations.json`; run `python offline_visual_review_contract.py VIDEO rois.json timeline.json decisions.json plan.json`; run `python offline_review_plan_clip_bridge.py VIDEO plan.json timeline.json explanations.json clips_new`.

Keep the original ROI JSON unchanged: its SHA-256 is bound to the timeline. Every output path must be new. No automatic equity/EV or action detection is performed in this workflow.

## Not verified / blockers

- Missing authorized annotated 3–5 minute PLO5/PLO6 recording. OCR accuracy, card/action reconstruction and actual hand boundaries remain unknown.
- Full 40–60 minute 1080p/30 FPS recordings, Windows, and the full repository suite remain unverified.
- Human declarations are not proof of poker facts; SHA-256 verifies file identity only. Monte Carlo equity and range-conditioned EV are separate components and are not yet wired into this browser workflow.

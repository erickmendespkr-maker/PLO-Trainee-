# Cycle 123 — Conservative offline betting-action triage

Scope: `docs/VIDEO_ANALYZER_SCOPE.md`. Offline/asynchronous PLO5/PLO6 recordings only. No live poker, playable tables, bot opponents, credentials, costs or production changes.

## Delivered

- `offline_betting_action_triage.py` consumes the **human-reviewed candidate snapshot** generated by `offline_hand_reviewed_snapshot.py` (Cycle 120) and emits an immutable JSON checklist for manual review. It does not modify any source record.
- Highlights missing hand timestamps, cards, pot/call/stack/range assumptions, unknown actors, same-timestamp actions, an actor acting after a visible fold, consecutive same-actor actions, ambiguous action labels, call/raise with no prior visible action, and **overlapping hand intervals on the same table**. Overlap on different tables is permitted.
- Checks candidate self-consistency (identity, variant, hashes, chronology, nonnegative amounts, source interval) and refuses input that claims verification/automatic authorization. Candidate hashes detect accidental mismatch but **do not authenticate** a human review chain; use the original draft/overlay/review files to independently verify provenance.
- Explicitly **does not certify legal betting**: the current action schema does not distinguish total raise-to from incremental raise, or capture blinds, per-player contributions, full turn order, pot size changes or effective stack transitions. Therefore pot-limit raise ceilings and legal min-raises cannot be checked responsibly. Warnings are not proof of mistakes.
- Uses strict JSON parsing (reject duplicate keys and NaN), bounded input, no symlink input, exclusive creation, no overwrites, restrictive permissions and source-change detection. No network calls or FFmpeg required for this independent step.

## Reproduce

From `video_analyzer/`:

```bash
python -m unittest -v test_offline_betting_action_triage
python offline_betting_action_triage.py reviewed_snapshot.json new_triage.json
```

Input must be a Cycle 120 reviewed snapshot JSON, with all evidence/math/selection gates false. Output must be a new `.json` file in an existing directory. For a **synthetic example only**, see the local demo package.

## Blockers and next cycle

- An authorized annotated 3–5 minute PLO5/PLO6 sample remains missing; real OCR/hand segmentation accuracy and 40–60-minute throughput are not verified.
- Extend action schema *as an explicitly optional reviewed annotation* with unambiguous contribution semantics, blind/ante, street opening commitments, player stacks and pot accounting. Then test a separate **conditional** pot-limit arithmetic validator on complete synthetic histories; do not mark partial traces illegal.
- Independently revisit the clip EOF boundary duration discrepancy with synthetic FFmpeg cases, without inventing frames.

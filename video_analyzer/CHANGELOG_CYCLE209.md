# Cycle 209 — verified offline session ZIP opener

## Scope
Adds `offline_session_bundle_open.py`, a local, offline handoff from the portable ZIP generated by `offline_session_bundle.py` to a browser-readable directory. This is not a poker client, live assistant, OCR system, or strategic grader.

## Usage
From `video_analyzer/`:

```bash
python offline_session_bundle_open.py /path/to/session.zip /path/to/NEW_directory
```

Then open `NEW_directory/index.html` in a browser. The new directory must not exist. The original session video is not bundled.

## Verification and safeguards
- Copies the input ZIP to a private temporary location; validates all file hashes and cross-file claims with `offline_session_bundle.verify()` before unpacking.
- Extracts only flat, verified inventory members, using explicit streams, byte limits and SHA-256 checks; never uses `extractall()`.
- Refuses existing destinations and symlinked source/destination paths; failed verification leaves no output directory.
- Keeps the manifest, MP4 cuts, review notes and conditional-analysis JSON files together with the generated HTML.
- Hashes prove file consistency, **not** that video contents, cards, ranges, actions, or EV assumptions are true.

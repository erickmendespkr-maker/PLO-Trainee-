# Ciclo 14 — integração offline sob revisão

Este ciclo trabalha exclusivamente com gravações enviadas pelo usuário. Não há captura em tempo real, apostas automáticas nem acesso a plataformas de pôquer.

Componentes preparados no pacote local: recuperação explícita de trabalhos interrompidos (sem repetição automática) e execução de análises matemáticas a partir de revisões humanas com validação de proveniência.

A publicação dos componentes depende de sincronização e de testes sobre um checkout da branch. A ausência de um vídeo autorizado impede validar a precisão visual em partidas reais.

# Bloco 11 — primeira comparação de uma mão real delimitada

Novo plo5_visual_validation.py compara campos explicitamente anotados com leitores PPPoker existentes, registra acertos, abstenções, falsos positivos e valores incorretos separadamente. Confere identidade do manifesto, hashes dos prints, PTS e banco; não certifica a anotação nem a mão. Entrada de amostras extraídas pelo mixed_review.extract, manifesto mínimo com source_sha256 e frames (file,pts,sha256), anotação vinculada pelo hash do manifesto, variant=5, platform=pppoker, table_id e anchors com expected. Campos não anotados são excluídos; null significa ausência esperada de rótulo. Uso: python video_analyzer/plo5_visual_validation.py PASTA_AMOSTRAS ANOTACOES.json bank_final.json NOVO_JSON.

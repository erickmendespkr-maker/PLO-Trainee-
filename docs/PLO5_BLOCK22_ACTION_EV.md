# Bloco 22 — EV incremental PLO5 (25/11/2026)

## Implementação

video_analyzer/plo5_action_ev.py reutiliza equity/prepare de plo5_equity.py (blob 5932bb94baf46323b6ddfe12dcdcf46aedf7a275), avaliador do bloco 20 e núcleo de showdown. Não altera motores legados. API Python analyze(s, method='auto', trials=2000, seed=0, max_exact=5000). Cenário estrito variant=5, hero, board, range, pot, hero_street, opponent_street, hero_stack, opponent_stack, bb, min_increment, rake_bps, rake_cap, rake_on_fold, aggressions. Valores financeiros em fichas inteiras, bb positivo; retorno incremental em BB. Pot inclui contribuições atuais. Stacks são saldos restantes. Range explícito de 1–10000 holdings com pesos inteiros até 100000 neste modelo. Cada alternativa agressiva {extra,call_bps} fornece extra acima do call e uma probabilidade de pagamento 0–10000 pontos-base por combinação na ordem do range original; até cinco sizings distintos. Bloqueadores removidos e massa renormalizada. Massa de call = soma peso legal * probabilidade de pagamento; range pago condicionado à mesma massa, evitando usar fold equity independente incoerente. Probabilidades são hipóteses, não estimativas de comportamento real.

C = opponent_street - hero_street. Fold (quando C>0) EV=0, call/check terminal EV=q*(P+C-rake)-C. Extra agressivo X >= mínimo declarado e <= min(P+C,stack_hero-C,stack_oponente). Apenas pagamentos integralmente correspondidos; chamadas curtas e raises não correspondidos são excluídos. Aritmética de sizing não é certificado de legalidade, reabertura ou ordem. EV agressivo = f*(P-rake_fold)+(1-f)*(q_called*(P+C+2X-rake_called)-C-X). No fold o extra não correspondido retorna; rake opcional sobre P+C. Rake terminal = min(teto,floor(pote*taxa_bps/10000)) em fichas inteiras. Sem regra de sala inferida. Pot odds sem rake C/(P+C), equity de equilíbrio C/(P+C-rake), se denominador positivo; null se inaplicável. Frações exatas para estimativas pontuais, inclusive massa de respostas; incerteza amostral propagada dos ICs marginais de equity, não intervalo conjunto nem erro de modelo. SHA-256 do cenário JSON canônico e opções de equity registrados.
